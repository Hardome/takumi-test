# Takumi: генерация изображений и PDF из JSX

Инженерный эксперимент с генерацией графики и документов без headless-браузера. TypeScript, React, Takumi и takumi-pdf.

## Запуск

Требуется Node.js 24. При первом запуске нужен интернет для загрузки шрифтов.

```sh
npm ci
npm run all
npm run docs
npm run report
npm run typecheck
```

- `generate` — таблицы с пагинацией в PNG.
- `examples` — градиенты, сетки, векторный билет и анимированный WebP.
- `docs` — API-справочник из `openapi.yaml` в векторном PDF.
- `report` — отчёт A4; можно передать путь к спецификации после `--`.

Результаты находятся в `out/`, галерея — `out/index.html`.

## Устройство и ограничения

Компоненты JSX описывают макет, движок Takumi выполняет отрисовку, а takumi-pdf формирует страницы A4. Размеры и отступы задаются в `src/config.ts`. Переменные `OG_WIDTH`, `OG_HEIGHT`, `PAGE_MARGIN_X`, `PAGE_MARGIN_TOP`, `PAGE_MARGIN_BOTTOM` позволяют переопределить их.

Поддержка CSS отличается от браузера. PDF требует наличия каждого используемого символа в подключённых шрифтах; декоративный символ замка заменён текстом, чтобы генерация не зависела от emoji-шрифта.

Это экспериментальный проект, а не универсальный генератор для произвольной спецификации OpenAPI.
